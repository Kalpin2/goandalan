# Copy Learning Log

Chronological append-only record of drafted vs human-edited copy, pattern IDs used, and real outreach outcomes per section 12.2 of `copy_intelligence_library.md`.

> **Privacy Guardrail:** For recycled IG content (`channel: caption`), store **`anonymized_name` only**. Never log real business names, WA numbers, or real addresses on recycled content.

------------------------------------------------------------------------

## Copy log schema (§12.2)

```yaml
copy_log:
  lead_id: ""
  channel: caption | cold_dm_1 | followup | cold_call
  date: ""
  display_name: ""
  category: ""
  city: ""
  has_website: true|false
  voice: ""
  sapaan: ""
  patterns_used: []
  levers: []
  word_count: 0
  had_specific_detail: true|false
  exploration_candidate: ""
  original_draft: ""
  final_text: ""
  edit_summary: ""
  outcome: no_reply | replied_neutral | interested | declined | ignored_48h | n/a
  outcome_at: ""
  notes: ""
```

## Cycle report template (§12.7)

```markdown
### Copy learning cycle N
- Period / sample: (n DMs, n captions, n calls)
- Repeated human edits found:
- Outcome signals (with raw counts and confounders):
- Gaps found:
- Candidate patterns added (max 3):
- Patterns recommended for approval:
- Patterns recommended for retirement or merge:
- Risks or things to verify:
```
